# KeyPop v0.6.0 — Consolidated Android Quality Build

**Branch:** feature/v0.6-consolidated-parity-20261106  
**Status:** alpha / experimental. No assertion of parity with Gboard, SwiftKey, Samsung Keyboard, Fleksy or Typewise.

## Delivered in a single next preview
1. Offline English, Urdu and Sindhi expanded word banks, conservative typo correction, contextual suggestions and opt-in local learning. Not a neural language model.
2. In-keyboard private rule-based Writing Tools: Formal, Polite, Concise, Punctuate plus contextual quick replies. They do not send text to cloud services.
3. 30 offline Sindhi/English/Urdu phrase translations. Unknown text requires the optional configured remote provider. Never represent limited phrasebook as general Sindhi translation.
4. User-curated GIF/sticker shelf: import compatible images/GIFs, pin, rename, search, share and copy. Encryption at rest. Not an online GIF search catalog.
5. Key-by-key width customization (65–175%), available inside Layout Lab and portable design export/import, without changing function keys.
6. Theme appearance enhancements: reduced-rate optional animated backgrounds, ripple key feedback, preference to honor Android motion settings. Opt-in to reduce resource use.
7. Private Performance Lab: opt-in keyboard *view construction* samples (not actual end-to-end key input latency), p50/p95, export and deletion.
8. Debug v0.6 package suffix `.previewv06` to avoid update-signature conflicts with previously built debug APKs. This is a fresh installation with separate data.
9. Regression tests for word prediction, conservative correction, writing, Sindhi phrasebook, geometry, media metadata and percentile math.

## Known blockers before competitor parity
- Production-quality statistical/neural language models for contextual predictions, grammar and autocorrect; comprehensive local word-frequency data for Urdu/Sindhi.
- Production-quality swipe recognition on all three languages and reliable input selection/cursor behavior in every supported editor.
- Online GIF/sticker discovery without a third-party API and configured licensing; current shelf is user-curated.
- Full general-purpose offline Sindhi translation; only a documented limited phrasebook is bundled.
- AI-backed generative writing beyond the local rules; would require explicit user opt-in, provider policy and key management.
- Live device measurements of memory/battery/crashes, keyboard latency/jank and head-to-head parity across budget, flagship and tablet/foldable hardware.
- Security audit and physical-device tests for Autofill/password vault and clipboard; do not use the alpha for banking secrets.
- Native iOS and desktop input-method applications. They cannot be delivered as part of an Android APK.

## Acceptance/validation
GitHub Actions must pass `testDebugUnitTest`, `lintDebug` and `assembleDebug`.
Device test: enable keyboard, switch languages, type RTL mixed scripts, use caps/backspace, change layouts and key widths, verify GIF import and sharing, confirm translation does not silently upload, compare on-device typing and memory to competitors, test high contrast and reduced motion.
