# KeyPop v0.9 — Material Teal + First-Launch Offline Packs + Settings IA

**Alpha development build:** visual inspiration from the user-provided Android keyboard screenshot. All assets, icons, interactions and code are KeyPop originals, not an exact proprietary Gboard copy. Full competitor parity is not yet validated.

## Screenshot-reference keyboard mode (mandatory)
- New installs default to **Gboard-style · Material Teal Glass**, with a dark teal background, luminous keycaps, independent corner hints and alphabetic shift/backspace keys.
- Compact top toolbar with seven original controls: grid/tools, clipboard, GIF/media shelf, settings, translate, theme preview, voice.
- Number row (0–9), QWERTY rows, staggered ASDF row, footer with ?123, emoji/comma, globe, English, period, question mark and enter.
- Long press on a key presents a KeyPop-owned popup strip with alternate punctuation/letters and drag selection; number-row keys expose fractions.
- Existing customizable skins, original layouts, size controls and languages are retained.
- Navigation-bar insets still reserve space above Android system navigation. Physical-device verification remains mandatory.

## First launch: model permission and management (mandatory)
- Android forbids custom dialogs during the operating-system package installation stage. The first KeyPop launch opens **Offline Language Packs** with explicit choice to download or skip.
- English and Urdu **ML Kit on-device translation model** download controls, Wi-Fi-only option, installed status, refresh and deletion.
- Bundled English/Urdu/Sindhi common phrasebook remains available immediately offline.
- English/Urdu offline speech models can be **requested** through Android SpeechRecognizer triggerModelDownload on supported Android versions. It does not guarantee download completion; the system speech provider owns model availability, storage and permission prompts.
- Sindhi full offline translator and Sindhi speech engine are **not bundled**. Voice recognition and translation for unbundled text are not completely independent of the system or model services.
- A reusable Language Pack Manager is accessible from KeyPop Settings. No translation model downloads start without affirmative user action.

## Settings and appearance consistency
- Settings are now grouped into separately navigated categories instead of displaying all options in one enormous vertical page.
- Home: Keyboard Setup, Offline Packs, Themes, Layouts, Typing & Size, Translation, Clipboard, Security, Try Keyboard.
- Back to All Settings, stable section heading and themed page background.
- Entering a menu, previewing a theme, opening tools or scrolling through settings never changes the keyboard theme.
- Theme and accent selections are saved together only when the user presses **Apply selected theme & accent**. Layout presets require a separate explicit Apply.
- Settings use the selected keyboard palette; after an explicit theme/preset Apply, settings redraw to that palette.

## Validation gate
- CI must pass debug unit tests, Android lint and debug APK compilation and publish five distinct Android APK variants.
- Device tests required: compare on-screen layout against the user-provided screenshot, verify popup holds with glide enabled, theme persistence across navigation and restart, permissions and model management on Wi-Fi-only and offline devices, real system speech model provider compatibility, and translation of full sentences.
- An emulator or GitHub CI build cannot prove screenshot-perfect matching or Android navigation-bar behavior on the user's phone.
