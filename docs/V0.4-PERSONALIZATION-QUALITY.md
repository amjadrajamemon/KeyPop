# KeyPop v0.4 Feature & Quality Snapshot

This is an **Android test preview**, not a certified competitor to Gboard/SwiftKey.

## Improvements over v0.3
- Layout Lab: editable, on-device key positions in English, Urdu and Sindhi. Tap two keys to swap or long-press a key to replace it. Five built-in English base arrangements: QWERTY, AZERTY, QWERTZ, Dvorak, Colemak. Functions remain non-remappable.
- Emoji Lab: locally indexed category navigation, keyword lookup, recent selection, favorite list (hold an emoji).
- Personal Dictionary: browse, search, add and delete words in each language; automatic learning is explicitly opt-in.
- Roman typing: optional on-device Roman Urdu and Roman Sindhi conversion on Space, with common-word rules plus phonetic fallback. Still experimental.
- Clipboard: image previews created asynchronously from encrypted screenshots; two-thread bounded decode service.

## Validations and boundaries
- Android `assembleDebug`, `testDebugUnitTest` and `lintDebug` required.
- No device-side instrumentation or head-to-head benchmarks available through CI.
- Key remaps are limited to 1–4 visible Unicode characters; cannot rearrange special controls, gestures or functions.
- Emoji list is an offline starter catalog, not an exhaustive Unicode or GIF/sticker search engine.
- Glide and local prediction remain experimental. Urdu/Sindhi phonetic transliteration, high-quality language models and offline Sindhi translation remain substantial gaps.
- The Android login vault and Autofill require real-device and security testing before sensitive credential usage.
- The debug app has a separate `com.aetherkeys.keyboard.preview` app ID. Never use this alpha for banking credentials.
- Cross-platform implementations for iOS/Windows are not present.
