# KeyPop v0.8 — Offline-first integrated keyboard (development alpha)

## New functionality in this branch
- **Hold-and-slide character selection:** The keyboard owns its visible alternate-character strip. Long-press now shows alternatives while a finger is still down; slide to choose and release to insert. Accents/Urdu/Sindhi alternates and fractions are bundled. Glide typing uses the same gesture recognizer rather than disabling long-press behavior.
- **Key customization on the keyboard:** Live changes to height, width, key spacing, label size, corner curvature and bottom position in the Resize panel. Number Row On/Off is in the same panel. Only layout-structural changes rebuild the key view.
- **Dedicated punctuation:** All six original layout presets expose comma, period and question mark without switching pages.
- **Discoverable familiar themes:** Original Gboard-style Material, SwiftKey-style Flow and Samsung-style One UI choices are clearly labeled in Themes and Layouts. No third-party logos, assets or proprietary implementations.
- **Visible predictions and corrections:** Offline context-driven word predictions even before the next word starts; tappable common English grammar and spelling corrections. It is a small explicit ruleset, not neural-level comprehensive grammar.
- **Offline phrasebook:** Includes common English↔Urdu, English↔Sindhi and Urdu↔Sindhi phrases, including “How are you ?” with optional punctuation spacing.
- **Voice Translate:** One KeyPop activity handles source/target selection, Android on-device-first voice recognition (where supported), text review, translation, and user-triggered insert/send. There is an explicitly requested Android speech-provider fallback; no silent cloud speech upload.
- **Automatic Translate on Send:** When enabled, detects script locally and translates a draft before invoking the receiving application's Send editor action, if supplied. If translation fails, the original draft stays intact.
- **Reboot default-keyboard status:** The settings home shows whether Android has selected KeyPop as default. Android normally remembers the default after reboot and unlock; no forced background startup or home-screen keyboard.

## Important remaining dependencies and limits
1. **ASR language models are not yet bundled inside this APK.** Recognition can run on-device if the device has an appropriate Android speech recognizer/model. The optional provider fallback can involve a network. Fully self-contained spoken Urdu/Sindhi needs compatible embeddable speech models and significantly more APK size.
2. **General English↔Urdu translation requires a downloaded ML Kit on-device model.** Bundled common phrases work entirely offline on first launch. Unknown Sindhi text requires an optional configured HTTPS provider; no general-purpose Sindhi model is bundled.
3. Predictive typing and grammar are rule/lexicon based, not as comprehensive as Gboard or SwiftKey.
4. Some Android messaging apps do not expose the Send editor action. KeyPop inserts translated text for manual sending in those apps.
5. Gesture-navigation bottom insets, system keyboard persistence, popups and resize controls must be tested on physical devices. GitHub CI alone does not verify them.
6. Each GitHub alpha debug version has its own test package ID, so changing from v0.7 to v0.8 requires selecting the new keyboard as Android default once. Once selected, Android normally persists it through restarts. Future signed stable builds should maintain one package ID and a consistent signing certificate.

**Release criterion:** Unit tests, Android lint and APK build all succeed; physical-device validation remains mandatory. Do not claim full competitor parity or completely self-contained ASR/offline Sindhi translation.
