# KeyPop GitHub compilation smoke build

This branch contains a minimal compile-test subset of the previously prepared AetherKeys source ZIP. It is **not** feature parity with the full ZIP.

Present: Native Android Input Method Service, English/Urdu/Sindhi layout switching, 15 selectable keyboard visual profiles, optional number row, key size settings, long-press alternates, on-device AES/GCM encrypted text clipboard history and pinning.

Not yet transferred from full source ZIP: direct translation and send, offline language translation, speech recognition, image clipboard, screenshot handling, saved login vault, Autofill service, biometric unlocking and richer premium themes. Do not test credential storage with this smoke build. The full source ZIP remains available separately.

APK from GitHub Actions is for testing only, unsigned with a release key and not Play Store ready.
