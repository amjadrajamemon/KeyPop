# KeyPop v0.5.0 – quality and portability candidate

## Implemented in this source update
- **Portable Theme/Profile Studio:** export/import JSON design files through Android's system document picker. Only allowlisted theme, geometry, and keyboard-layout values; no clipboard entries, passwords, learned words, or personal typing history. Rejects invalid and oversized files; imports require confirmation.
- **Spacebar editing gestures:** slide to move the caret; long-press for English / Urdu / Sindhi language selection. Can be disabled in settings.
- **High-contrast mode:** enforce legible key labels and outlined keys across all 15 visual profiles.
- **Roman text handling:** improved Shift/Caps behavior when typing Roman Urdu and Sindhi using Latin keys.
- **Safer key remapping:** reject special keyboard command labels when editing user layouts; automated regression tests added.

## Prior v0.4 capabilities retained
15 designed themes, editable language layouts, English/Urdu/Sindhi, customizable geometry, interactive settings, local personal dictionary, searchable emoji, clipboard pins/history and screenshot import, translation, voice provider integration, optional Autofill and a local credential vault.

## Evidence and limitations
GitHub workflow runs :app:testDebugUnitTest :app:lintDebug :app:assembleDebug.
No automated CI result proves real-device performance, accessibility, translation quality, or security parity with Gboard, SwiftKey, Samsung, Fleksy, Typewise.
Major missing capabilities include advanced language-model prediction, robust multilingual glide, built-in cloud-independent Sindhi translation, GIF/sticker search catalogs, native iOS/Windows keyboards, and device-based battery/memory/stability benchmarks.

**Release gate remains issue #2; this is a debug preview, not production/financial-credential safe software.**
